# v0.2 evaluation — 21 held-out, model-only

This directory contains the 21-sample evaluation used for the v0.2 release note. All scores are from the model's own outputs; no human rewrite, no 7B teacher, no API call at inference.

## Files

- `final21_metrics.json` — per-sample metrics for base / v0.1 / v0.2
- `final21_bar_corporate.png` — Corporate-style comparison chart
- `make_chart21_corporate.py` — deterministic chart script (numbers are never generated by an image model)

## Setup

- Base: Qwen2.5-3B-Instruct, `gguf/qwen25-3b-base-Q4_K_M.gguf`
- v0.1: `gguf/fluorestsentsiya-3b-preview-Q4_K_M.gguf`
- v0.2: base GGUF + `gguf/fluorestsentsiya-3b-preview-v0.2-lora-f16.gguf`
- 21 held-out prompts; `max_tokens=2400`; outputs trimmed at 2,000 Chinese characters on a sentence boundary
- Decoding: base/v0.1 `repeat_penalty=1.1`; v0.2 `DRY multiplier=0.8`, `repeat_penalty=1.15`

## Results

| Version | Mean CJK chars | 2k hit | rep4 | Duplicate sentence rate | distinct4 |
|---|---:|---:|---:|---:|---:|
| Base Qwen2.5-3B | 1,120.2 | 1/21 | 0.0762 | 0.00% | 0.9238 |
| v0.1 | 830.1 | 4/21 | 0.2503 | 17.32% | 0.7497 |
| v0.2 | 1,497.7 | 11/21 | 0.1827 | 2.70% | 0.8173 |

v0.2 vs v0.1: mean CJK +80.4%; rep4 −27.0%; duplicate sentence rate −84.4%; distinct4 +9.0%.

## Metric definitions

- Mean CJK chars: mean number of Chinese characters after trimming each output at 2,000 characters on a sentence boundary.
- 2k hit: fraction of the 21 samples with ≥1,800 Chinese characters after trimming.
- rep4: 4-gram repetition rate = (total 4-grams − unique 4-grams) / total 4-grams; a lower value indicates less repetition.
- Duplicate sentence rate: number of exactly repeated sentences / total sentences.
- distinct4: unique 4-grams / total 4-grams; a higher value indicates greater 4-gram diversity.
- Relative change = ((v0.2 − v0.1) / v0.1) × 100%.

## Limits

- Only 11/21 reach 1,800+ characters; the mean is 1,498.
- distinct4 improves by 9.0%, not 20%; the human target on the same 21 is 0.9534, only +14.9% over v0.1. This metric is close to its ceiling.
- The base model has lower rep4 and higher distinct4 than v0.2, but writes only 1,120 characters and reaches 2k in 1/21; it is not task-compliant.
- Role/causal consistency was not blind-rated at n=21.
- Lech/POLLUX/WPB/Burrows were not re-run for v0.2; v0.1's original numbers are preserved in `docs/legacy-v0.1.md` and are not mixed with the v0.2 21-sample table.
- CWB 4.36 from the parent project is contaminated by 10/12 prompts and is not reused.
